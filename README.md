# To-Do List Web App

A simple and beginner-friendly To-Do List application built using **HTML**, **CSS**, and **JavaScript**. This project was created as part of my journey into web development to learn the fundamentals of building interactive web applications.

## Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Clean and responsive user interface
* Real-time task management without page reloads

## Technologies Used

* **HTML5** – Structure and content
* **CSS3** – Styling and layout
* **JavaScript (ES6+)** – Functionality and interactivity

## What I Learned

Through this project, I gained hands-on experience with:

* Creating and structuring web pages using HTML
* Styling elements with CSS
* Handling user interactions with JavaScript
* Working with DOM manipulation
* Using event listeners
* Managing application state in a simple frontend project
* Organizing code for better readability and maintainability

## Project Goal

The primary goal of this project was to strengthen my understanding of core web development concepts and build a solid foundation before moving on to more advanced projects and frameworks.

## Getting Started

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project folder:

   ```bash
   cd todo-list
   ```

3. Open `index.html` in your browser.

No additional dependencies or installation steps are required.
